# 螺旋丸 · 手势实验（单手完整版）

用一只手凝聚螺旋丸。保持张掌约 2.6 秒即可蓄满，移动手掌可以带动球体。掌心朝上时球悬在手上方，竖掌时球贴近掌缘。收拢手掌，球会消散。

## 本地运行

在仓库目录下启动静态服务器：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

在浏览器打开 <http://localhost:8000>，选择「手势模式」并允许使用摄像头。也可以先用「效果预览」体验球体。手势模式需要 localhost 或 HTTPS。识别模型随项目自带，摄像头画面在浏览器内处理。

## 更新

网页源码和静态资源在 `dist/`。 `app.js` 负责应用流程，`hand*.mjs` 负责手势识别与跟随，`effect.js` 负责绘制。修改后刷新本地预览即可，无需构建。
